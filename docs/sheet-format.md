# Sheet Format

The first row should contain the column headers. The basic question format is:

| Column | Required | Description |
|---|---|---|
| Question | Yes | Question text |
| Option A | Yes | First answer choice |
| Option B | Yes | Second answer choice |
| Option C | Yes | Third answer choice |
| Option D | Yes | Fourth answer choice |
| Answer | Yes | Correct option, such as `A`, `B`, `C`, or `D` |
| Reasoning | Yes | Explanation for the correct answer |
| Feedback | No | Optional feedback shown to the respondent |

The legacy versions may also use `Level2`, `Level3`, difficulty, tags, and other fields. Follow the column order expected by the selected script before importing bulk data.
