# Clareon-Form-Maker
Appscript Code for both legacy and reduced code for automatic form making while using google sheets and google forms API.
Making of Google forms using this script(s)

The legacy code although works to a certain extent, most of its features belong to a backend.
these include storing form questions, making questions with an API from a LLM, processing and storing responses and creating and publishing the forms.

Publishing is still an issue after the form has been made so contribution needed.

Since this App is not known yet by Google, it may be flaged as unsafe to use while initialisation.
When you finish setting up or initialising make sure to to replace the template form key to one existing in your Google forms.

The study-forms-v1.gs has been modified to have only basic functions and we are still modifing it to have more basic functions to ease content creation keeping a professional format.
